# 博博私人訂製抽籤系統 v1.0

這是一個可直接部署到 GitHub Pages 的純靜態網站，不需要伺服器、資料庫或安裝套件。

## 使用方式

直接開啟 `index.html` 即可使用。若要測試離線快取，請透過本機網站伺服器或 GitHub Pages 開啟（瀏覽器不允許在 `file://` 模式註冊 Service Worker）。

可在網址加入設定參數，例如：

`?students=40&cooldown=3&speed=7&duration=5`

## 部署到 GitHub Pages

1. 將本資料夾內所有檔案上傳到 GitHub 儲存庫根目錄。
2. 在儲存庫的 **Settings → Pages** 選擇從分支部署。
3. 選擇包含這些檔案的分支與根目錄，儲存後等待 GitHub Pages 產生網址。

## 私隱與付款介面

- 系統只處理學號，不收集姓名或其他學生個人資料。
- 課堂紀錄只保留在目前頁面的記憶體中，重新載入後清除。
- Premium 付款介面純屬娛樂，不連接任何支付服務，也不傳送或儲存輸入內容。
